# Elischa Kongolo Portfolio

Personal software engineering portfolio for Elischa Kongolo.

The site presents the work behind one simple claim: **I ship working software end-to-end: mobile, web, and backend.**

## Pages

- **Home**: introduction, claim, selected work, and contact CTA.
- **Work**: case studies for the SASL App, All Around Sneakers, and Online Banking projects.
- **About**: background, working principles, and technical toolkit.
- **Contact**: LinkedIn and GitHub links for opportunities and collaboration.

## Featured projects

- [SASL App](https://github.com/NathiDEV-dot/SASL-APP.git) - Flutter and Dart mobile learning application for South African Sign Language.
- [All Around Sneakers](https://github.com/ElischaKongolo/all-around-sneakers.git) - PHP and JavaScript e-commerce platform with product management, authentication, and checkout flow.
- [Online Banking Application](https://github.com/ElischaKongolo/OnlineBankingApp.git) - C# and SQL Server application with authentication, user management, and account CRUD operations.

## Built with

- HTML
- CSS
- JavaScript
- Netlify or GitHub Pages for free static hosting

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server. No package installation or backend is required.

## Deployment

This is a static site. Upload the project folder to Netlify Drop or enable GitHub Pages from the `main` branch. The root `index.html` is the homepage.

## Repository purpose

This repository stores the source code and version history for the portfolio. The site is intentionally static at launch; dynamic features such as a contact form can be added later if the portfolio needs them.
